# 家事ライフログ MVP

「片付けられない」のではなく「途中で止まる」家事を、1タスクずつ完走できるように伴走するアプリ。

## 設計の核

- 1タスクだけを大きく表示。他のタスクは見せない（選択肢を見せると壊れる）
- タスク開始したら他のタスクへの切り替え不可
- 経過時間は裏で記録するだけ。画面には出さず、完了時に「○分でできた」と振り返り
- 目標時間という概念は持たない（時間制限のプレッシャーを生まないため）

## ファイル

- `index.html` — MVP本体
- `speech-test.html` — 音声出力テスト用（家事中の読み上げ実験）
